# Paper

## Title

**Fetal-CARE: Collaborative Annotation with Reviewer-Stratified Expertise for Fetal Ultrasound Standard Plane Classification**

## Authors

Lakshminarayanan M*, Srivibha Parthasarathy*, Keerthi Ram, Shyam Ayyasamy, Suresh Seshadri, Manojkumar Lakshmanan, and Mohanasankar Sivaprakasam.

*Equal contribution.

## Abstract

Manual labelling of fetal ultrasound standard planes is challenging because of variability in acquisition, imaging systems, image quality, and human annotations. Fetal-CARE is a human-AI collaborative framework based on Evidential Deep Learning that allocates cases to reviewers according to estimated uncertainty and reviewer expertise. It uses EDL-derived vacuity as the routing signal, with calibrated thresholds separating low-, moderate-, and high-vacuity cases for junior, senior, and expert reviewers. On 22,987 images from 1,500 patients across 20 standard planes, Fetal-CARE reduced total review time by 22.1% compared with conventional AI-assisted verification while preserving reviewer verification quality.
